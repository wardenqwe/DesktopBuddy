# 🐾 Desktop Buddy

Интерактивный пиксельный питомец, который живет прямо на вашем рабочем столе Windows. Он не мешает работать, но всегда рядом!

## ✨ Возможности
- **Живой анимированный питомец**: шагает, моргает и смотрит по сторонам.
- **Живет в трее**: не перекрывает окна и всегда под рукой. Двойной клик по иконке — скрыть/показать.
- **Умный сон**: засыпает, если вы не трогаете мышь/клавиатуру, и мгновенно просыпается от любого действия.
- **Настройка цветов**: выберите статический цвет или включите плавный радужный перелив.
- **Пузырь с мыслями**: иногда дает полезные советы (например, «Попей воды!»).

## 🚀 Как запустить
1. Перейдите в раздел [Releases](../../releases).
2. Скачайте последний архив `DesktopBuddy_v1.0.zip`.
3. Распакуйте в любую удобную папку.
4. Запустите `DesktopBuddy.exe`.

*(Для работы требуется Windows 10/11)*

## 🖱️ Управление
- **Перетаскивание**: Зажмите левую кнопку мыши на питомце, чтобы переместить его.
- **Настройки**: Кликните правой кнопкой мыши по иконке в трее -> «Настройки».
- **Выход**: Кликните правой кнопкой мыши по иконке в трее -> «Выход».
